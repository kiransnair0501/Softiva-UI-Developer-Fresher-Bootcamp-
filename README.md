# NexaTech Company Landing Page

A responsive company landing page built using HTML5 and CSS3 as part of my UI development training.

## What I Learned

* Semantic HTML
* Forms and input types
* HTML5 form validation
* Tables
* Basic accessibility
* CSS selectors
* Box Model
* Typography and spacing
* CSS variables
* Flexbox
* CSS Grid
* Responsive design
* Media queries
* Hover and focus states

## Page Sections

* Responsive Navigation Bar
* Hero Section
* Services Section
* About Section
* Pricing Table
* Contact Form
* Footer

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Design
* Media Queries
* Git
